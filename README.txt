ISHWARYA PORTFOLIO — QUICK START

Files:
- index.html: page structure and section content
- style.css: responsive visual styling
- main.js: rendering and mobile navigation
- skills.js, experience.js, projects.js, certifications.js: editable portfolio data
- assets/: place approved images here

OPEN LOCALLY:
Open index.html in a browser. For a local development server, run:
  python3 -m http.server 8000
Then visit http://localhost:8000

IMPORT INTO SAP BUSINESS APPLICATION STUDIO:
1. Download and unzip this project on your computer.
2. In SAP Business Application Studio, open your portfolio dev space.
3. Click "Files & Folders" on the Get Started page, or use the Explorer panel.
4. Upload the unzipped files/folder. If you upload a ZIP, extract it in the workspace if the UI offers extraction; otherwise upload the extracted folder's contents.
5. Open index.html and preview using a local/static web preview or Live Preview extension if available.

BEFORE PUBLISHING:
- Replace YOUR_EMAIL@example.com in index.html with your professional email.
- Update LinkedIn and GitHub links with your actual profile URLs.
- Verify employment dates, role descriptions, certification names, and links.
- Remove confidential or client-sensitive project details.
- The current portfolio URL is included as a link; this starter does not copy its source code.
